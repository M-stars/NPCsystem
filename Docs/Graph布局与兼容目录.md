# Graph 布局与 NPC 模板兼容目录

本增量源码已完成独立 Roslyn 编译；真实 Unity 测试与界面验收由本轮验证记录确认。不能把本页的操作说明当作测试已通过的证据。

## 分组与注释

打开 `Tools > Social Simulation > Graph Workbench`，选定图资产后：

1. 在画布右键选择“布局 / 创建注释”。双击注释标题或正文可编辑，也可在右侧属性面板编辑。拖动注释移动，拖动右下角调整大小；右键可改主题和字号。
2. 框选节点、注释，右键选择“布局 / 将所选节点与注释分组”。未选择成员时创建空分组。分组不允许嵌套。
3. 拖动分组标题一起移动成员。将节点/注释拖入分组可调整归属；选中成员后右键“从分组移出所选项”。
4. 删除分组会保留成员。删除节点或注释会同时清理成员引用。复制分组会复制它的节点、注释及内部连线，全部生成新 ID；只复制节点或注释不会把原分组关系附到副本。
5. 保存图资产后可重开。创建、编辑、拖动、缩放、成员变更、删除和粘贴均支持 Undo / Redo。

`GraphDocument.Groups` 保存标题、位置与成员 ID；`Notes` 保存标题、正文、矩形、主题和字号。旧图没有这些字段时视为空集合，文档 schema 保持 v1。元数据不进入执行计划或修订摘要；纯布局编辑不递增执行版本。执行顺序继续由连线 `Order` 决定。

## NPC 模板兼容目录

节点库顶部增加“内容目录”“NPC 模板”和“仅显示兼容项”。默认内容目录优先取当前场景的 `SocialCatalogProvider`，没有时取工程中的第一个目录；请确认实际工作对象。

- 内容目录必须整体通过 `BuildRegistry` 注册验证。无效目录显示原因，不提供动作绑定。
- NPC 模板必须是该目录直接引用的 `NpcPackageAsset`。选中模板后，动作根据其真实能力、骨骼、执行器依赖和动画映射检查兼容性。
- 缺少必需能力、骨骼冲突、执行器或必需表现时，条目禁用并显示具体原因。
- 能力没有要求表现，且缺少动画映射时，显示可用但仅执行逻辑的降级状态。该状态允许使用，不把它显示成有完整动画。
- 动作按钮提示所需能力、目标、资源与执行器。当前协议尚没有完整动作专属参数模式；这部分不能从目录提示推导为已经完成。
- 选择模板后，“应用”会递归检查行为图与子图。存在不兼容动作或未知定义时拒绝应用，保留当前运行计划。宿主仍会执行原有运行绑定检查。

当前领域包只公布动作 ID，家庭/工作/校园执行器的实际定义存在模块中。这些尚未通过共享接口接入的动作显示“缺少已注册 ActionDefinition 与执行器绑定，兼容性未知”，不会被列为确认可用。已有图不因此被删改；未选模板时仍可交由实际运行宿主验证。后续接线应从同一个注册来源提供定义，避免编辑器另建一套业务动作猜测表。

## 验收用例

新增 `GraphProductTests` 覆盖布局保存重开、执行摘要不变、Undo / Redo、复制分组/空分组/注释、删除清理、整组移动、原生分组回调、6 类兼容结果、嵌套子图拒绝、真实模板目录筛选及应用阻断。是否通过以真实 Editor 结果为准。

画布控件沿用 Unity GraphView 的 [Group 实现](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Modules/GraphViewEditor/Elements/Group.cs)，没有在玩家运行时引入 UnityEditor 依赖。
