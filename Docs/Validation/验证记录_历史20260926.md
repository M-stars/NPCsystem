| 100/300 NPC 纯逻辑压测 | 已执行 | 3600 Tick、20 Tick 错峰评分与 60 Tick 资源申请/释放，详见 [LogicBenchmark](Benchmarks/LogicBenchmark.md)。300 人平均 0.1270 ms/Tick；无可见角色、NavMesh、动画、物理或渲染，不能推算完整场景 FPS。 |

压测中 `GC.GetAllocatedBytesForCurrentThread()` 给出 `0.00 MB`，但托管堆净增长分别为 1.58 MB（100 人）和 6.14 MB（300 人），且发生 Gen0 回收。该线程分配读数在当前 Unity Mono 环境不可作为零分配证据；应视为 **未可靠取得**。

完整 27 人场景另采样 t=350→8365：27 个可见 NPC，导航峰值至少 21 个；43,367 帧/267.55 秒，墙钟平均约 6.17 ms/帧（**包含 Unity Editor 与 MCP 开销，不是独立主线程 CPU 耗时或发行构建帧率**）；Gen0 回收增加 197 次，托管堆约 115.65→116.72 MB。该采样与上面的纯逻辑压测不可直接比较。

## 商业使用边界

当前是单机 Unity 6 社会仿真框架与跨领域样例。联网、任意运行时脚本模组、实时大模型推理、全量 ECS、复杂金融和供应链不在此版本范围。已导入 Kenney 角色验证了 Humanoid 与 Idle/Run；坐姿、讲话和持物专用动画未通过素材验证。100/300 人纯逻辑结果仅说明内核路径成本，不构成 100/300 个可见角色的帧率承诺。
