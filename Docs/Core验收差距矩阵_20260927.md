## 调用方必须接入的约束

1. **地域管辖**：每个有归属的 `PlaceState` 必须配置真实 `OwnerCollectiveId`。`SubjectScope` 可选 `Members`、`Jurisdiction`、`MembersOrJurisdiction`。只有 tag 相同不能作为另一个组织的管辖依据。
2. **撤任与撤权**：依赖岗位获得的授权，应在创建 `Grant` 时传 `RoleAssignment.Id`。无角色绑定的授权是独立授权，不应假定撤任会自动删除它。退出集体会撤销该成员在该集体中的授权。
3. **事件效果预算**：实际规则命令执行器必须把原始 `WorldEvent` 传给 `TryCommitEffect`；同步回调内部的服务事件会继承根因。校园 `EmitRuleCommand` 已核对 `currentRuleEvent` 和目标身份后使用此入口，并为规则条件提供 `TimeSeconds`。新增规则 host 仍需独立接线与测试。
4. **延迟因果链**：要保留源事件的延迟操作，通过 `Schedule(..., parent: source)` 排队。不能长期缓存一个已结束的源事件，之后再作为新的父事件重新提交。
5. **内容指纹**：Core 指纹覆盖已注册的 manifest 数据，不包含 FBX 文件、Avatar 或 Animator Controller 的二进制内容。Unity 存档还需要验证相应资产依赖版本。
6. **会话资源**：动作向会话移交必须经 `ActivityService.AttachResource` / `ActionExecutionContext.TryTransferToSession`；任意改写 Token 的 `OwnerScopeId` 不代表建立了正确的参与者所有权。
7. **记忆满额**：`Remember` 返回 false 时，重要未完成义务仍应保留在承诺/义务权威记录中。界面与领域模块可以记录“记忆已满”，不能为了写入新消息无限扩充个人记忆。

## 地区与存档风险的回归结果

| 一个 Tick 跨完整关闭再开放周期 | `RegionClockSystem` 调用 `CrossedClosingBoundary`，触发中间关闭的必要清理 | 4 项边界 EditMode 用例及 `ReopeningOutsideHoursAndCrossingAWholeCalendarPeriodCannotLeakTokens` |
| 卸载活动中的一间教室 | 取消相关图、导航和资源，其他教室保留；可立即存档恢复 | `UnloadingActiveClassroomPreservesOtherClassroomAndCanReloadImmediately` |
| 直接行程长期等待、暂停后大步推进 | `RequestTravel` 使用有限正预算，保存绝对模拟截止点和 Tick 提交结果；读档不重新获得完整预算 | `PausedSingleStepExpiresTravelAndKeepsFailureAfterSaveLoad` |

入场预约现在同时计算逻辑居民、活动行程与 `PendingAdmissions`。真实到达和提交之间的高并发容量竞争仍应作为目标场景压力测试项，不能以普通人数校验替代。

当前门禁检查目标地区的逻辑准入。入口连接和地点邻接已校验，但没有限制 NavMesh 路径穿越中间的关闭地区。真实几何封路需要入口障碍、导航区域约束或按地区路径分段申请。

9 月 30 日独立程序基线出现 Agent 早于 Surface 就绪时的创建失败消息。Prefab 默认禁用 Agent、由导航适配器接管启停的修复已通过双场景导航 PlayMode 专项；本批 Windows 构建与双场景 Player 复测已通过，运行错误为零，旧启动消息消失；这是下一批依赖协议开发前的基线，结果见[验证记录](验证记录.md)。
