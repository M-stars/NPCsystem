# 人格原型与个体差异

每个 NPC 场景实例的 `SocialNpcMarker` 可配置 `PersonalityArchetype`。`Id` 是稳定的原型标识，`Mean` 是外向、尽责、合作、好奇、敏感及价值偏好的中心值；`StandardDeviation` 控制同原型成员的差异。三个 `Coupling` 分别把社交、职责、探索相关维度连接到共同的潜在因子，同时给每个维度保留独立扰动。

没有配置时使用 `balanced` 原型。创建角色时按世界种子、原型 ID 与 NPC 实例 ID 生成一次人格；相同输入得到相同结果，其他 NPC 的创建顺序和动画帧数不会改变它。生成结果进入 `AgentState.Personality` 并随世界存档，不在每帧重抽。

可以在 Inspector 配置原型，或在生成角色时调用 `SocialNpcMarker.SetPersonalityArchetype(value)`。运行时也可直接调用 `PersonalityGenerator.Generate(worldSeed, agentId, archetype)`。均值必须在 0～1，偏差在 0～0.5，关联系数在 0～1，非有限值会拒绝。

人格影响效用评分中的偏好与适配程度，不是职业、资格或权限。职责、能力、已知信息和实时需要仍由各自服务判定。相关性生成的 3 项 `PersonalityArchetypeTests` 已包含在 2026-09-27 的 253/253 EditMode 通过报告中；样例当前使用默认原型，不声称能从少量参数自动推断现实人物。
