## 已实现

- NPC 六目录包同时注册 Humanoid 与 Generic。组合场景有 25 个 Humanoid、2 个 Generic；模型、Avatar、Controller 和坐下、坐姿、工作、行走等动画已接入。
- 组合场景包含校园、家庭、工作交易三个领域；独立社区包含 7 人、4 地区、家庭与工作交易两个领域，内容目录不含校园包。
- 家庭照料、班次工资、购买、社团活动使用统一动作图；检查点保存执行阶段与效果去重状态。
- 地区包包含边界、入口、邻接、所有者、营业日历与访问条件。关闭、卸载和立即保存恢复已有回归；准入条件控制目标地区的逻辑进入，物理门和中间地区路径封锁仍需场景实现。
- 通用知识服务保存来源、渠道、置信度、同源合并、转述冷却与遗忘；校园制度告知及商店状态参与采购决策已接入：NPC 只读取个人已知信息，现场发现暂停服务后可转述给同地角色。NPC 人格按原型、世界种子与稳定实例 ID 生成，并随存档保存。
- **事件触发的跨领域目标重评**：Core 的 `GoalReevaluationService` 监听个人知识事件（学到、更新、Tick 期遗忘），按“代理+主题+主体”注册的重评规则去重调度下一 Tick 的重评事件；领域模块注册各自的处理器，不依赖校园内容。工作交易顾客获知复业或记忆过期后自动重启采购；家庭早餐创建时经家庭频道公告，离家获知的成员回家后迟到加入，未获知者不会加入。重评规则由领域模块在初始化/读档时重新注册，调度事件随世界快照恢复。
- **关系衰减**：未强化的关系按半衰期向中性漂移（默认半衰 2 天、宽限 1 小时，可配置），强化即重置；熟悉度不衰减。衰减随 Tick 静默进行，`DecayedFor` 与设置进入快照，读档后从记录的债务继续。
- **真实感测试场景（2026-10-29）**：`RealisticSocialWorld.unity`（组合世界的视觉增强副本，业务逻辑与 CombinedSocialWorld 完全一致）。菜单 `SocialSimulation/Samples/Enhance Realistic World` 幂等地把 Kenney Furniture Kit / City Kit（均为 CC0）家具替换到交互点上、沿街区布置建筑与道路、以 RenderMeshes 全场景重烘焙 NavMesh，并用与 NPC 运行时相同 agentTypeID 的显式 filter 审计 58 个交互锚点可达性。非挖孔家具（座椅等）以 `ignoreFromBuild` 排除出烘焙，挖孔家具（桌/柜/沙发）保持锚点 0.5m 净空。已知边界：NPC 仍在平坦占位地面上寻路（地面未替换纹理）；灯光/天空未做美术级调整；该场景未接入 Player 冒烟脚本。
- 通用组织治理支持可替换策略、授权任务请求和成员独立接受/拒绝；承诺支持多方同意、真实账本核销、履约、违约、迟到履约与共同终止。现有领域尚未全部改用这些通用服务。
- 图工作台包含规则试运行、类型与单位比较、子图导航、暂停后应用、NPC 模板兼容性筛选、持久化分组与注释。布局编辑不改变执行修订。
- Core 世界快照为 **v3**，Unity 运行存档为 **v5**；包含知识和承诺历史。工作交易检查点升级为 **v3**，保存服务暂停状态，拒绝旧 v2；家庭检查点仍为 v2。旧开发存档明确拒绝，尚无自动迁移。导航保存截止时间和已提交结果，读档提交异常会尝试恢复原世界、NPC 姿态与业务状态。
