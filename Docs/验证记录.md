## PlayMode 已覆盖的运行链路

- 组合场景同时加载校园、家庭与工作交易；25 个 Humanoid 与 2 个 Generic 正确运行，坐下后保持坐姿循环，Generic 可进入 Walk。
- 独立社区完成照料、领薪、购买与社团日程，并从进行中的班次恢复；组合日程覆盖课程、规范与经济效果，存档后不重复结算。
- NPC 销毁后注销逻辑实体并释放预约；地区关闭/卸载清理资源和活动，暂停后可立即保存、恢复。
- 保留独立停用的槽位；非营业时间重开与跨完整营业周期不会泄漏 Token。
- 活动教室卸载后保留其他教室的活动；不兼容存档与无效导航不改写当前世界。
- 暂停单步可以使行程按模拟时间到期，失败结果经保存恢复保留；读档提交阶段发生暂态领域异常时回滚世界及 NPC 姿态。

- 知识采购专项中，NPC 实际到店发现暂停服务并产生个人观察，同地转述让另一角色推迟采购；JSON 恢复后接收复业公告，经显式再次请求启动动画采购，账本扣款和物品交付完成。
- 导航专项检查两个场景加载、NPC 关闭再启用和离网旧姿态恢复，未出现原先的导航启动错误。
- 2026-10-26 事件重评批次：个人知识变化（学到、更新、遗忘）会自动重跑该 NPC 注册的目标选择；顾客在获知复业或记忆过期后无需显式请求即自动重启采购，真正到达柜台时仍按客观服务状态结算。家庭早餐创建时经家庭频道公告，离家而获知的成员回家后经 `agent.arrived` 迟到加入活动；未获知的成员即使到达也不会加入。

这些结果覆盖报告中的具体路径。知识已完成一个工作交易端到端链路；其他领域，以及组织治理和承诺的真实动作、动画和 UI 接入仍需独立验收。

## 已定位并修复的运行问题

- Generic 包未注册：加入内容目录，两名工人使用 Generic Prefab。
- Humanoid 坐下动画被 AnyState 反复触发：限制进入 SitDown 的来源，明确片段循环属性。
- 无校园成员资格的 Prefab override 未保存：显式记录实例属性修改。
- 已在家庭地区仍导航到中心而错过早餐：无交互点且已在目标地区时直接开始活动。
- JsonUtility 将空调度父事件恢复为空对象而使未来日程被拒绝：使用显式 `HasParent`，保持独立事件与因果事件的区别。
- 子图检查点达到 Unity 递归序列化深度限制：改用独立 JSON 片段，三层子图及各层状态往返已有回归。
- 社团绑定不存在的 `run.01`，购买行程预算过短：修正为 `run.1`，购买总预算改为可配置的 1200 模拟秒。
- 响应式选择器先尝试新动作而未释放旧资源：先做只读前置检查，再取消旧分支；9 项 Unity EditMode 回归通过，真实复杂资源宿主仍需专项验收。
- 地区卸载、营业时间跨越、导航超时与读档失败的状态清理：由本轮 13 项 PlayMode 中的专门用例覆盖。

## 性能与交付边界

纯逻辑测量在 Unity Editor 内同步执行，不包括可见角色、动画、NavMesh 或渲染。当前线程分配栏显示 0.00，但缺少足够测量证据，不能表述为“零分配”。100/300 个可见角色的帧时间、GC、内存峰值与长时间稳定性尚需独立测量。

`Tools/Capture-UnityWindow.ps1` 已实测后台捕获指定 Editor 窗口及 Windows 150% DPI；上述 Observer 两张运行截图与操作报告已完成对应验收。Graph Workbench 的常用停靠尺寸、分组操作、断点与宿主歧义仍需自己的人工验收，不能借用 Observer 结果关闭。发布所需能力和未关闭实现见 [Core 差距矩阵](Core验收差距矩阵_20260927.md)与 [Graph 差距矩阵](Graph验收差距矩阵_20260927.md)。新领域需要显式内容与执行器，现有证据不支持“任意现实社会机制自动模拟”或“绝对没有 bug”的结论。
