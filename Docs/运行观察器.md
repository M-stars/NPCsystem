# 运行观察器

## 打开与选择世界

在 Unity 打开 `Tools/Social Simulation/Runtime Observer`，进入 Play Mode。只有一个运行世界时自动绑定；有多个世界时，在 Hierarchy 选择目标世界根对象或其下的 `SocialNpcMarker`。随后从 NPC 下拉框选角色。

窗口顶端显示世界 ID、Runner 对象名、Tick 与模拟时间。绑定的是具体 Runner，NPC ID 相同也不会转到另一个世界。选中的 Marker 未在所属世界注册、世界已销毁或场景已卸载时，界面清空并禁用运行控制，要求重新选择。不要把“没有个人记录”与“未绑定有效世界”混为一谈。

`Pause/Resume`、`Step` 和速度设置只控制当前绑定世界。单步先暂停，再推进完整 Tick。观察面板约每 0.25 秒刷新一次，不通过查看或筛选修改仿真状态。

## 个人知识

“个人知识”只列当前 NPC 可查询的记录，包括：

- 主题、对象、陈述、当前置信度，以及直接观察或收到信息。
- 原始来源、最后传达者、原始渠道和当前渠道、原始事件 ID。
- 发生、获知和到期时间，转述次数及保护状态。

筛选不区分大小写，可匹配主题、对象、陈述、来源、渠道或原始事件 ID。先筛选再取最多 64 条，摘要分别显示个人记录总数、匹配数和实际显示数；匹配超过显示上限时应缩小条件。无匹配或无当前个人知识时给出明确提示，不会从全世界事件补出该 NPC 未获知的信息。

受保护记录可以在有效期结束后继续保留，并显示“已过有效期（保留历史）”。保留历史不代表它还能满足新的知识决策条件；有效期仍由决策服务校验。

## 决策依据

“目标评分”显示最近一次选择及各候选的职责、需求、人格、社交、承诺、时间、体力和后果评分。知识条件另外显示：

- 期望陈述与匹配、矛盾、冲突、未知或配置非法的结果。
- 候选允许/拒绝、未知策略与扣分。
- 决策当时采用的陈述、置信度、来源、渠道及原始事件。

个人知识区的置信度按**当前模拟时间**计算；决策记录保存**当次选择时**的置信度和信息副本。因此时间推进、后续转述或消息过期后，两处数字可以不同。两处表达不同时间的状态，不能用当前值覆盖历史决策原因。

收到新消息本身不保证 NPC 立刻重新规划。工作交易样例会在采购日程或显式再次请求时重新评估，详见[知识与信息传播](知识与信息传播.md#工作交易领域中的接线)。

## 图、资源与事件

其他分区显示身份与多重角色、需求与情绪、图执行、资源预约和会话、规范与因果事件。事件筛选与知识筛选分别生效。

图诊断按当前世界、NPC、图实例与版本匹配。换世界、换 NPC 或读档后会清理不再匹配的轨迹；已确认的终态失败在活动图被移除后仍可作为历史显示。嵌套或不属于当前 Runner 的提供者、来源不明确的全局轨迹不能自动混入当前 NPC。

此面板有助于追踪具体 NPC，但尚未替代规则图中完整的权限拒绝、去重、跨 Tick 根因和最终业务提交视图；相关差距见[Graph 矩阵](Graph验收差距矩阵_20260927.md)。
