## 最新实现与证据

最新实现是事件触发的跨领域目标重评与关系衰减（2026-10-26）：

- Core 新增 `GoalReevaluationService`：监听 `knowledge.learned/updated/forgotten`（遗忘事件由 `KnowledgeService.Tick` 在到期/衰减时发出，容量淘汰不产生事件），按“代理+主题+主体”规则去重调度下一 Tick 的重评事件；规则由领域模块注册，不进快照，读档后重新注册，未触发的调度事件随世界快照恢复。
- 工作交易：顾客对商店可用性的知识变化自动重跑采购选择（获知复业或记忆过期即自动重试；客观柜台校验、账本幂等不变）。家庭：早餐创建时经家庭频道公告，离家获知的成员回家后 `JoinLate` 迟到加入；未获知者不会加入。两个领域都不依赖校园内容。
- 关系衰减：`SocietyService.Tick` 对未强化关系的 `Liking/Trust` 按半衰期向中性漂移（默认 2 天半衰、1 小时宽限，`ConfigureRelationDecay` 可配，0 关闭）；`Relate` 即强化重置；`DecayedFor` 与设置随 Core 快照 v3 保存（旧档缺失时保留默认值），读档后从记录继续。熟悉度不衰减，衰减不产生事件。

## 项目范围与已知边界

项目目标是跨场景、跨领域复用的 NPC 与地区模拟系统，不应把校园演示等同于产品范围已经完成。当前有组合场景（校园、家庭、工作交易）和不含校园包的独立社区场景；NPC 资产包按常见内容拆分为 Prefab、Model、Rig、Animations、Materials、Textures，并已接入 Humanoid 与 Generic 模型/动画。场景数量、资产包和功能细节见[当前工作进度](当前工作进度.md)与[标准资产包](标准资产包.md)。

继续开发时优先核对以下尚未关闭的通用性与商业验收项：

1. 知识、治理和多方承诺服务尚未在全部领域形成真实端到端接线；长时数据归档及自动迁移也未完成。
2. 跨实例黑板、明确的动作参数模式、完整规则上下文隔离和冲突分析仍有缺口；需以多领域执行器和内容配置验证，而非只通过 Core 单元测试。
3. 知识重评的剩余边界：店员因个人知识被拒的采购日程不会自动重建（需日程/重排机制）；容量淘汰不产生遗忘事件；遗忘循环周期由记录保留期决定。
4. Graph Workbench 的人工窗口验收及复杂宿主/断点交互仍需专项检查。
5. 100/300 NPC 的现存性能报告是纯逻辑 Tick 测量，不含角色渲染、动画、NavMesh、物理和实际可见 FPS；需要独立的可见场景性能、GC、内存及长时间稳定性验证。
6. 目前只验证报告中列出的场景路径；不能据此声称任意现实机制均可自动模拟，也不能声称已无明显 bug 或达到全面商业验收。
